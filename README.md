# 1A2B 線上多人 PK 遊戲

依照專案規劃書開發中的 React、Express 與 Socket.IO 多人 1A2B 遊戲。

## 開發啟動

```bash
npm install
npm run dev
```

前端預設為 `http://localhost:5173`，後端為 `http://localhost:3001`。

## 測試

```bash
npm test --workspace=server
npm run build
```

## Render 部署

專案包含 `render.yaml`。連接 GitHub 儲存庫後，Render 會執行正式建置並以 `/health` 檢查服務狀態。

## 加入房間

房間密碼為選填。公開房可由首頁的在線房間大廳直接加入；有設定密碼的房間仍需輸入密碼。房主分享的完整邀請網址含專用邀請碼，持有網址的人可免密碼加入，請把完整邀請網址當作私人入房憑證。

## 玩法與房間狀態

- 可選 4～7 位不重複數字；答案與 A/B 判定只由伺服器處理。
- 單人模式無須密碼，建立後立即開始。多人房可加入 0～9 位電腦玩家，真人與電腦合計不超過房間上限（最多 10 人）；電腦有低、中、高三種難度，猜測只根據自己的歷史提示，不讀取答案。
- 首頁顯示目前在線的房間、真人與電腦人數。房間在記憶體中，服務重新啟動後會失效；目前未設定全站房間硬上限。即時數字不是服務容量保證。
- 等待室與對戰畫面共用房間聊天室，最多保留 100 則、每則 200 字；訊息隨房間失效而消失。
- 每間多人房最多 4 位觀戰者。觀戰者不占比賽玩家名額，遊戲進行時只能看到公開 A/B 結果，結算後才能看到完整猜測紀錄。比賽玩家與觀戰者只能在開局前切換身分。

## 有界線上負載測試

```bash
node server/test/load.mjs https://onea2b-online-api.onrender.com 5 10
```

測試會建立指定房間與玩家、各猜一次，最後退出測試房間。參數上限為 10 房、每房 10 人，適合驗證一個負載樣本，不代表 Render 免費方案的絕對承載上限。請勿在重要對局進行時執行。
